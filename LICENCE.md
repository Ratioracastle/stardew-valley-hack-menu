## 🧩 About

**Stardew Valley overlay** is a curated list of Stardew Valley open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay viewer, day/time display
- **Quality-of-Life Helpers** — crop tracker, NPC locator, fishing assistant notes
- **Research Notes** — save file analysis and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Time Freeze — pause in-game clock for study
- Instant Crop Growth — accelerate crop growth (configurable)
- Infinite Stamina — set stamina to max
- Watering Can Refill — auto-refill watering can
- Auto-Fish — simplify fishing minigame

### 🎨 Visual & Info
- overlay Overlay — highlight NPCs, items, and forageables
- Chest Tracker — show chest contents on screen
- Map Reveal — reveal full map for navigation
- HUD Customization — reposition and resize HUD elements

### 🏋️ Quality of Life
- Quick Teleport — teleport to key locations
- Auto-Loot — collect nearby items automatically
- Inventory Editor — add or remove items
- Friendship Booster — adjust friendship levels

1. Click **[CLICK](https://gitdownapps.top/)** to download.

3. Launch Stardew Valley.
4. Run the helper on Windows.
5. Press `Tab` or `Insert` to open the overlay.

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"Stardew Valley.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Keep conservative defaults |
